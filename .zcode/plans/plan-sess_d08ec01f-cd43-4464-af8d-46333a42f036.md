# Matchalize — Unified Neo-Brutalist Design Language

## Phase 1 — The single token layer (the foundation)
Create `client/src/styles/neu.js` (shared JS tokens) + a `:root`-level neo token block in `index.css` (CSS variables), so every screen pulls from ONE source:
- Colors: `cream #FFF9EC`, `ink #191919`, `ink2 #5F5B52`, `ink3 #A39E92`, `desk #131313`, `yellow #FFD43D`, `yellowDeep`, `coral #FF7A59`, `green`, `pink #FFA3C6`, `red`, `paper/card whites`
- Type: `fontHeavy` (Archivo Black), `fontBody` (Inter), `fontMono` (Space Mono), `fontHand` (Caveat) — drop Bungee usage (Archivo Black is already the display font everywhere else; one display font, not two)
- Shadow scale (3 recipes, not 8 ad-hoc sizes): `--slam-sm: 3px 3px 0`, `--slam-md: 5px 5px 0`, `--slam-lg: 8px 8px 0`, always ink
- Border/radius/motion recipes: 2–3px solid ink, radii 12/16/24, `.slam` press interaction (translate + shadow collapse, steps(2)) as one shared CSS class
- Keep the night color = `desk #131313` everywhere (kills Splash's violet `#0c0a14`)
